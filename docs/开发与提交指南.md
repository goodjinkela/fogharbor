# 开发与提交指南

> 面向《移动应用开发基础》期末大作业。工程已能构建通过，剩下的是在你的 DevEco Studio 里签名、跑模拟器、截图录屏、最后提交。

---

## 一、打开工程

1. DevEco Studio → `File > Open`，选择 `D:\FogHarbor`（包含 `build-profile.json5` 的那一层）。
2. 首次打开会 Sync，等待右下角进度结束。
3. 如果提示 SDK 版本不匹配：`File > Project Structure > SDK`，确认使用 `HarmonyOS 5.0.5 (API 17)`。

---

## 二、配置签名（必须，否则装不上模拟器）

1. 右上角登录华为账号（`File > Settings > Huawei Account` 或右上角头像）。
2. 账号需完成**实名认证**，否则自动签名会失败：去 [开发者联盟](https://developer.huawei.com/consumer/cn/) 完成实名。
3. `File > Project Structure > Project > Signing Configs`，勾选 **Automatically generate signature**，点 `Apply`。
4. 回工程根目录 `build-profile.json5`，确认 `products[0].signingConfig` 已指向生成的配置。

常见错误：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `No signingConfig found` | 未勾选自动签名 | 按上面第 3 步操作 |
| 提示需要实名认证 | 账号未实名 | 开发者联盟实名后再登录 |
| 构建成功但安装失败 | 设备与 profile 不匹配 | 删除 `~/.ohos/config` 下的旧 profile 重新生成 |

---

## 三、启动模拟器

1. `Tools > Device Manager > Local Emulator`。
2. 选择 `Huawei_Phone`（HarmonyOS 5.0.5，API 17）→ 点击 ▶ 启动，冷启动约 30–60 秒。
3. 验证连接：

```powershell
& 'D:\HUAWEI\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe' list targets
```

出现设备号即成功。

卡顿处理：模拟器分配 4GB 内存，与 IDE 同时运行建议机器内存 ≥16GB；关闭其他占内存程序，或在 Device Manager 里把内存调到 2048MB。

---

## 四、运行与验收

1. 顶部选择模块 `entry`，设备选择 `Huawei_Phone`，点 ▶。
2. 按下面清单逐项验证：

- [ ] 首页显示「开始调查」，点击进入故事页
- [ ] 打字机逐字显示，轻触可跳过
- [ ] 做出 2–3 次选择，属性条实时变化
- [ ] 线索不足时，条件选项为灰色并显示「需要 线索 ≥ N」
- [ ] 存档页保存到槽位 1，杀掉应用后重开，首页出现「继续调查」并能恢复
- [ ] 走到终局，出现结局面板，图鉴点亮

杀进程方式：模拟器最近任务里划掉应用，或

```powershell
& 'D:\HUAWEI\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe' shell aa force-stop com.goodjinkela.fogharbor
```

## 六、Git 提交

工程已初始化并关联 `https://github.com/goodjinkela/fogharbor.git`，身份已配置为：

```
user.name  = goodjinkela
user.email = goodjinkela@users.noreply.github.com
```

**注意**：为绕过本机 Steam++ 加速器的证书问题，该仓库设置了 `http.sslVerify=false`。若之后关闭加速器，建议执行：

```powershell
git -C D:\FogHarbor config --unset http.sslVerify
```

提交节奏（评分看的是过程，不要一次性提交）：

```powershell
git add -A
git commit -m "feat(rule): 新增结局优先级判定"
git push
```

推荐提交信息前缀：`feat` / `fix` / `docs` / `test` / `refactor`。每次提交只做一件事，说明写清楚改了什么。

## 九、常见问题

| 问题 | 处理 |
| --- | --- |
| 构建报 `spawn java ENOENT` | 用 DevEco 内置 JDK：把 `D:\HUAWEI\DevEco Studio\jbr\bin` 加入 PATH |
| 首页一直显示「正在恢复进度」 | preferences 初始化失败，检查是否在模拟器/真机运行，而非 Previewer |
| 杀进程后进度丢失 | 确认 `putString` 里有 `await store.flush()` |
| 读档后出现两个故事页 | 读档逻辑必须先 `pop()` 再 `push('Story')` |
| 中文提交信息乱码 | 终端执行 `git config --global core.quotepath false`，并使用 UTF-8 终端 |
